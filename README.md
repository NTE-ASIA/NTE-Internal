# NTE Internal — TP Files

> **Updated for Version 1.3.7 (Global)**

Teleport coordinate files for **Neverness to Everness** using the Pipsi TP file format

The files are organized so you can load saved teleport locations directly instead of entering coordinates manually

## Files

All TP files are stored in [`Files`](./Files)

Some data is grouped into folders by map, activity, or category for easier navigation

## How to Use

1. Open [`Files`](./Files)
2. Download the `.txt` file you want to use
3. Place the file in the folder below

```text
C:\Program Files\Neverness To Everness\Client\WindowsNoEditor\HT\Binaries\Win64
```

4. Open **Pipsi**
5. Open the **Teleports** tab
6. Enter the TP file name in **File Name**
7. Load the file

![How to use TP files](howtouse.png)

## Notes

- Keep the `.txt` extension
- The file name entered in Pipsi must match the downloaded file name
- TP files may require updates after major game changes
